Documents

NDA, DPA and data handling.

Engagement Pre-Requisites: Prior to commencing active reconnaissance, source code auditing, or adversary simulation, Cipherforge and the client execute our Mutual NDA and Data Processing Agreement. Read our core execution documents below.
Document CF-NDA-01

Mutual Non-Disclosure Agreement (NDA)

Our standard bilateral agreement designed specifically for offensive security engagements. Enforces strict confidentiality on vulnerability findings, source code, network architecture, and technical telemetry for three years under New York law.

3-Year Term Zero Public Disclosure New York Law
View Mutual NDA
Document CF-DPA-02

Data Processing Agreement (DPA)

Institutional framework clarifying the Client as Data Controller and Cipherforge as Data Processor. Incorporates technical and organizational security controls, subprocessor oversight, strict purpose limitations, and 48-hour breach notification.

GDPR / CCPA 48h Breach SLA SCCs Supported
View Data Processing Agreement
Document CF-DHP-03

Data Handling Policy

Operational security requirements for all client data: AES-256 encryption in transit and at rest, multi-factor authentication, quarterly access reviews, and mandatory retention caps (90 days for raw logs, 12 months for engagement reports).

AES-256 90-Day Log Cap Zero-Knowledge Enclaves
